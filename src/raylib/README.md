NOTES
-----

- Raylib, rlgl, and rcamera use the official raylib  
binaries that are generated automatically by Github Actions.  
They can be found on raylib's website.  
Raygui uses custom binaries generated by me, also using  
Github actions.  

- Currently, only arm64 binaries are distributed for MacOS.  
Windows and Linux support amd64, arm64, and i386.  
Wasm is only distributed as a static library, and can be changed  
with "-define:RAYLIB_WASM_LIB=..." and "-define:RAYGUI_WASM_LIB=..." respectively.  

- Shared versions of libraries can be activated using  
"-define:RAYLIB_SHARED=true" and "-define:RAYGUI_SHARED=true" respectively.
